Flow mimarisi · 5 sayfa, ~3 dakika

Tek sayfa "concept primer" değil. Konu hissedilerek öğrenilsin diye 5 atomic sayfa: her biri tek bir bilişsel görevi yapar. Mini-quiz ortada, özetten önce — kullanıcının hâlâ taze öğrenme bağlamındayken kontrol etmesi için.

Consolidation

Sıralamanın gerekçesi: Hook (limbic prime) → Tanıtım (semantic schema) → Karşılaştırma (örüntü) → Quiz (retrieval, hâlâ taze) → Özet (chunk to memory). Quiz'i en sona koyarsak retrieval boş olur — özet quiz'in cevabını verir, kullanıcı kendi düşünmemiş olur.

Japanese-aware font stack

// Latin: SF Pro Rounded; Japanese: Hiragino Sans (system-served on iOS)
// Both have rounded geometry — visual cohesion. Avoid Noto/Source — squarer.
font-family: ui-rounded, "SF Pro Rounded", "Hiragino Sans", system-ui;

// CRITICAL: do NOT bold Japanese glyph at small sizes (<14pt).
// Hiragino bold strokes blur kana counters at small sizes. Use weight 500–600.

11

Pedagojik prensipler

UI kararlarının altındaki cognitive science. Designer'ın "neden böyle?" sorusuna cevap.

1 · Concrete → Abstract → Concrete

Hook (concrete: glyphler), Tanıtım (abstract: tanımlar), Karşılaştırma (concrete: cümleler), Quiz (concrete + retrieval), Özet (abstract: chunk). C→A→C→C→A pattern. Saf abstract'tan kaçar.

2 · Tek bilişsel görev / sayfa

Her sayfada en fazla bir yeni schema gelir. Tanıtım'da iki tanım var ama paralel (aynı schema parçaları). Quiz tek soru. Özet sadece review. Kullanıcı her sayfada "bu sayfada ne öğrendim?" sorusuna tek cümleyle cevap verebilmeli.

3 · Retrieval before consolidation

Quiz özetten önce. Eğer özet quiz'den önce gelirse kullanıcı doğru cevabı zaten okumuş olur — retrieval boş geçer. Testing effect: aktif retrieval pasif okumadan ~2x güçlü.

4 · Wrong reveals correct (no shame loop)

Quiz wrong state'inde doğru cevap aynı ekranda accent ile gösterilir. Kullanıcı yanlışı tekrar denemek zorunda değil — istiyorsa "TEKRAR DENE" var. Hata utanılacak şey değil, fark edilecek şey. Bu disiplin streak'lerin sürdürülebilirliği için kritik.

5 · Skip is a feature, not a sin

"Atla" tüm sayfalarda var. İleri seviye kullanıcı zaten konuyu biliyor olabilir; explanation onu yavaşlatmamalı. Telemetri ile ölç: skipped_at_page rate %30+ ise konunun bir önceki ünitede yetişen olduğu anlamına gelir, içeriği basitleştir.

Copy guidelines

Tone: arkadaşça öğretmen. İkinci tekil ("sen"). Soru cümleleriyle başlatma (Headspace'in tuzağı). İmplicit confidence: "yapacaksın", "anlayacaksın" — "yapabilirsin"den daha güçlü.

SwiftUI sketch · DefCard


struct DefCard: View {
  let particle: String
  let translit: String
  let label: String
  let body: String
  let accent: Bool

  var body: some View {
    VStack(alignment: .leading, spacing: 8) {
      HStack(spacing: 14) {
        // glyph box
        Text(particle)
          .font(.system(size: 32, weight: .bold, design: .rounded))
          .foregroundStyle(accent ? .pkAccent : .pkTextPrimary)
          .frame(width: 56, height: 56)
          .background(accent ? .pkAccentMuted : .pkSurfaceMuted, in: .rect(cornerRadius: 16))

        VStack(alignment: .leading, spacing: 2) {
          Text(translit.uppercased())
            .font(.system(size: 11, weight: .bold, design: .rounded))
            .tracking(0.88)
            .foregroundStyle(accent ? .pkAccentInk : .pkTextTertiary)
          Text(label)
            .font(.system(size: 16, weight: .semibold, design: .rounded))
        }
        Spacer()
        SpeakerButton()
      }
      Text(body)
        .font(.system(size: 14, weight: .medium, design: .rounded))
        .foregroundStyle(.pkTextSecondary)
        .lineSpacing(4)
    }
    .padding(.horizontal, 18).padding(.vertical, 16)
    .background(.pkSurface, in: .rect(cornerRadius: 16))
    .overlay(RoundedRectangle(cornerRadius: 16).stroke(.pkDivider, lineWidth: 1))
  }
}

Anti-examples · ders anlatımı tuzakları

    
Lesson explanation'lar genelde başarısız çünkü designer ders kitabı yazmaya çalışır. Aşağıdakiler en sık tuzaklar.


    

      

        
✗ Don't

        
Tek sayfada tüm konu (wall of text)

        
Kullanıcı kaydırır, hiçbir şey hatırlamaz. Bilişsel yük tek seferde patlamasını yapar.

      

      

        
✓ Do

        
5 atomic sayfa, sayfa başına tek görev

        
Her sayfa kendi içinde bir "mikro-completion" verir. Pacing duygusu yaratır.

      


      

        
✗ Don't

        
Quiz en sonda (özetten sonra)

        
Özet kullanıcıya cevabı verir; quiz boş retrieval olur, testing effect kaybolur.

      

      

        
✓ Do

        
Quiz ortada (sayfa 4), özet en sonda

        
Aktif hatırlama hâlâ taze schema üzerinde çalışır. Özet sonra chunk olur.

      


      

        
✗ Don't

        
Wrong state'de doğru cevabı saklamak

        
"Tekrar dene, doğru cevabı bulana kadar." Frustration loop. Kullanıcı tahmine geçer, anlama kaybolur.

      

      

        
✓ Do

        
Wrong state aynı ekranda doğruyu accent ile gösterir

        
Yanlış + doğru tek snapshot. Kullanıcı farkı hemen görür. İsteğe bağlı tekrar deneme var.

      


      

        
✗ Don't

        
Confetti / 🎉 emoji / "Süper!" feedback

        
Tantanalı, premium hissi yok eder. Çocuk uygulaması hissi. Asıl ödül anlama, performansa değil.

      

      

        
✓ Do

        
"Doğru! 'Kim?' sorusunun cevabı …" — gerekçeli

        
Feedback kuru değil, eğitici. Kullanıcı doğruyken bile neden doğru olduğunu öğrenir.

      


      

        
✗ Don't

        
Japanese glyph + Latin font karışık (ör. Inter + Noto)

        
İki farklı geometri, iki farklı counter. Cümle "patchwork" görünür, premium hissi gider.

      

      

        
✓ Do

        
SF Pro Rounded + Hiragino Sans

        
İkisi de rounded geometry. iOS system-served, ekstra font yok. Cümle bütünleşir.

      


      

        
✗ Don't

        
"Atla" yok / dimmed / disabled

        
İleri kullanıcıya saygısızlık. Dropout artar. Kullanıcı zorla okuma yapmaz.

      

      

        
✓ Do

        
"Atla" tüm sayfalarda görünür, küçük confirm sheet

        
Saygılı opsiyon. Telemetri ile içerik kalitesi ölçülür.

      


      

        
✗ Don't

        
XP / streak alıştırma yapmadan açıklamadan verilir

        
Açıklamayı sıkıcı bir vergi gibi göstermek için "ödül" eklemek. Kullanıcı sadece XP için skip eder.

      

      

        
✓ Do

        
XP/streak sadece alıştırma sonrası

        
Anlama kendi başına yeterli ödül; "Konu tamamlandı" rozeti sadece görsel kapanış.

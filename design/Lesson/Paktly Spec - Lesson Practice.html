01

Flow mimarisi · 1 ders ≈ 4–5 dakika

Her alıştırma micro-feedback (band) verir; her milestone macro-feedback (interstitial) verir; ders kapanışı meta-feedback (4 metric + chest) verir.

Daily streak (ders bazlı, ayrı sistem)

Ders bittiğinde streak.lastActiveDay bugün ise no-op, dün ise +1, başka ise sıfırlanır. Completion ekranındaki "5 günlük seri" bandı bu sistemin yansıması — combo (in-lesson) ile karıştırılmamalı. 

// streak update — completion'da çağrılır
function updateDailyStreak(state) {
  const today = new Date().toDateString();
  const last  = state.streak.lastActiveDay;
  const diff  = daysBetween(last, today);

  if (diff === 0)      return state;                  // already counted today
  if (diff === 1)      return { count: state.count + 1, lastActiveDay: today };
  return { count: 1, lastActiveDay: today };           // reset
}

01

Palette · Paper white + Duo green

Beyaz/krem zemin (saturasyon az değil — beyaz kasıtlı; ders içerikleri zaten yoğun olacak, home rahat olmalı), tek dominant accent: #58CC02. Sarı sadece streak için, kırmızı sadece can/hayata kaybında. Mavi-yeşil karışıklığı yok — yeşil tek hâkim.

Light mode

Dark mode

Rationale (200 kelime)

Beyaz background, doygun yeşil accent. Paktly bir öğrenme aracı — ekranda zaten harf, kelime, çevirme, mikrofon var. Background kırılgan/kremli olursa ders ekranıyla çelişir. Beyaz, ders içeriğinin nefes almasını sağlar; sıkıcı değil çünkü yeşil node'lar canlı.

Yeşilin tek dominant olması bilinçli. Yeşil = "doğru, ilerle, başardın." Bu duygu home'da her node'da tekrar etmeli. Sarı (streak) ve kırmızı (can) sadece kendi anlamlarında çıkar — accent olarak hiç kullanılmaz. Bu disiplin, kullanıcının renkleri "anlam haritası" olarak öğrenmesini sağlar (gestalt).

Dark mode'un zemini saf siyah değil (#131F24, hafif teal-aside). Saf siyah OLED'de can sıkar ve yeşil üstüne çıktığında halo efekti yapar. Bu zemin, yeşili patlatır ama yormaz.

3D shelf renkleri tonal: yeşil node'un shelf'i daha koyu yeşil (#3A8A00), grinin shelf'i daha koyu gri. Renk sistemi kapalı kalır, "Word'den çekilmiş gri shadow" hissi olmaz.

03

Path geometry

Sen "132pt yetersiz, daha açabilir misin?" dedin — açtım: 116pt nodeGap + 84pt çap = 200pt center-to-center vertical pitch, ders ekranında ferah görünür. Swing pattern düz aşağı-yukarı değil, sinüsoid kıvrım: [-78, -26, 26, 78, 26, -26] — 6'lı döngü, monoton değil.

Node
diameter: 84pt
shelf depth: 8pt
Spacing
vertical gap (center→center): 200pt
↳ this = 84 (node) + 116 (clear gap)
Swing pattern
x offsets: [−78, −26, +26, +78, +26, −26]
cycle: 6 nodes, sine-like
Connector
stroke: 4pt dashed (6 / 8)
color: divider token
curve: cubic Bezier (smoother than quadratic)
⚠ NOT solid, NOT gradient — dashed reads as "path not yet walked"

Node states · 4 variants

State logic

Completed
Yeşil face, koyu yeşil shelf, beyaz tick. Tap → soft "ding" + haptic light, ders detayını re-open eder (review mode).
Current
Beyaz face, koyu ink shelf, ink star outline. 3pt ring (accent) face etrafında. Sürekli breath animasyonu (1.6s, 1.0→1.04). Tap → lesson modal'ı açar.
Upcoming
Beyaz face, soft gri shelf, küçük dot. Tap → "Finish current lesson first" toast (haptic warning).
Locked
Muted face (surfaceMuted), aynı gri shelf, lock icon. Opacity tam — sadece renkler dimmed (40% saturation azaltma değil; renk paleti zaten kontrol). Tap → "Unlock by completing previous packs" toast.
05

3D button physics

Shelf 8pt (önceki 7pt'den 1pt fazla, tactility daha net). Press = face shelf'le buluşur (translateY 8pt). Curve değil cubic-bezier(0.2, 0.8, 0.2, 1), 90ms — Apple'ın "spring out" feel'i ama deterministic.

Variants — tap to feel the press

Timing

press in90 ms
press out160 ms
hapticon press

Curve: cubic-bezier(0.2, 0.8, 0.2, 1) — fast in, slow out. SwiftUI: .spring(response: 0.18, dampingFraction: 0.65)

SwiftUI sketch

struct ShelfButton: View {
  @State var pressed = false
  let face: Color
  let shelf: Color
  var body: some View {
    ZStack(alignment: .top) {
      Capsule().fill(shelf)
        .offset(y: 8)
      Capsule().fill(face)
        .offset(y: pressed ? 8 : 0)
        .animation(
          .spring(response: 0.18, dampingFraction: 0.65),
          value: pressed
        )
    }
    .frame(height: 56)
  }
}
06

"START" callout

Sallanmayı bıraktık. Yeni: soft breathing — scale 1.0→1.04, 1.6s ease-in-out, sonsuz döngü. Apple Health'in metric card'ları gibi. Daha az invaziv, daha premium hissedilir, accessibility ayarı "reduce motion" ile devre dışı kalır.

↑ Bak — fark eder, ama dikkat çalmaz. Sürekli sallanan callout'tan ÇOK farklı.

Geometry

shape: rounded pill + triangle pointer (8pt)
width: 86pt
height: 36pt
label: "START" · 13pt · weight 700 · tracking 0.08em
background: textPrimary
color: background
offset y: −68pt above current node center
↳ önceki −56pt pack başlığıyla çakışıyordu
↳ yeni: 84/2 + 36/2 + 12 boşluk = 68

Animation

// SwiftUI
.scaleEffect(animating ? 1.04 : 1.0)
.animation(
  .easeInOut(duration: 1.6)
   .repeatForever(autoreverses: true),
  value: animating
)
.onAppear { animating = true }

Anti-examples · what NOT to do

    
Genel his "ölü" diye yazmıştın. İşte ölüye götüren patternler.


    

      

        
✗ Don't

        
Solid line connector between nodes

        
Yol "yürünmüş" gibi durur, oysa upcoming node'lar henüz yapılmadı. Dashed = "henüz yapılmamış yol".

      

      

        
✓ Do

        
Dashed cubic Bezier, divider color

        
Henüz yürümediğin yol = kesik çizgi. Subtle, hayatta.

      

      

        
✗ Don't

        
Gradient backgrounds (mavi-mor, sarı-turuncu)

        
AI slop signature. Saturasyon yapay görünür, dikkat çalar, premium hissi yok eder.

      

      

        
✓ Do

        
Flat solid backgrounds, accent yalnız node + button'da

        
Renk gücünü tek yere odaklamak ona değer kazandırır.

      

      

        
✗ Don't

        
Sallanan / wobble eden START callout

        
Tantanalı, dikkat sürekli kapar, 30 saniye sonra kullanıcı uyumsuzlaşır. Çocuk uygulaması hissi.

      

      

        
✓ Do

        
Soft 1.6s breathing (scale 1.0→1.04)

        
Periferik dikkat sürer, doğrudan dikkat çalmaz. Reduce-motion kapatır.

      

      

        
✗ Don't

        
SF Symbols karışık aile (filled + outline + multicolor)

        
Görsel kakofoni. Kullanıcı her ikonu yeniden parse eder.

      

      

        
✓ Do

        
Custom abstract glyphs, aynı stroke / aynı corner radius

        
Tek görsel dil. Kullanıcı durumu ikonun şeklinden değil, rengin kontrastından okur (daha hızlı).

      

      

        
✗ Don't

        
3 farklı saturated renk (mavi + yeşil + turuncu)

        
"Mal gibi yıkık" demiştin — paradoxically tam tersi. Çok renk = renk anlamı kaybolur, sahte canlılık.

      

      

        
✓ Do

        
1 dominant accent (yeşil), sarı + kırmızı sadece kendi anlamlarında

        
Renk = bilgi kanalı. Yeşil "ilerle", sarı "streak", kırmızı "kayıp". Disiplin = canlılık.

      

      

        
✗ Don't

        
Native UITabBar (standard iOS chrome)

        
Markaya özel hiçbir hiss bırakmaz, "100. iOS appi" hissi.

      

      

        
✓ Do

        
Floating pill tab bar (blur, accent active state)

        
İlk dokunulan unsur tab bar — orada marka konuşur.

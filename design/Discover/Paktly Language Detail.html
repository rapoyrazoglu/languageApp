Paktly · Japanese detail

Tek liste, segment chip'leri (All / Official / Community + level filter). Official rozeti, Reviewed mührü, Beta uyarısı. Yapan avatar + ad + beğeni. Upload akışı uygulamada değil — community pack'ler GitHub repo + pull mekanizmasıyla DB'ye geliyor.

Quality tier'ler

  • Official (yeşil tick rozet, "Paktly Original" yazar): Paktly ekibinin yaptığı, garantili pack'ler.
  • Reviewed (yeşil-muted rozet): Community pack ama Paktly'nin kalite testlerinden geçmiş — accuracy, audio, pacing onaylı.
  • Beta (sarı rozet): Henüz incelenmemiş, 3–5 gün içinde ekip değerlendirir. Kullanıcılar hala görür ama riski biliyor.
  • Upload akışı uygulamada yok: yapımcılar GitHub repo oluşturur ve push eder; backend pull eder, DB'ye yazar. Bu ekran sadece sonuçları gösterir.
  • Renk politikası: pack hue'ları çeşitlilik için (mor/turuncu/teal/sarı/mavi) — bunlar accent değil, içerik kimliği. Yeşil hâlâ tek dominant brand renk: rozetler, CTA, accent ink.
  • Filtre tasarımı: All/Official/Community içinde count chip'leri (tıpkı App Store'un "Apps · 14" formatı). Sonra level filtreleri (N5/N4/N3) eşit yükseklik, eşit pill — tipografi disiplini.
